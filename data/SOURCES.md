# Data Sources

RepoPilot uses publicly available open-source repositories as demo data for testing and demonstration purposes.

## Demo Repository Used

| Repository | URL | Purpose | License | Date Accessed |
|---|---|---|---|---|
| vercel/next.js | https://github.com/vercel/next.js | Demo data for architecture, dependencies, and codebase analysis demonstration | MIT License | 2025-01-01 |

## Notes

- This data is used solely for demonstration purposes in the RepoPilot hackathon submission.
- No private, confidential, or personal data is used.
- No repository credentials, secrets, or tokens are stored or displayed.
- All environment variable names shown are generic examples; no actual secret values are displayed.
- The metrics, file counts, and dependency lists shown in the demo are representative examples based on the public repository's actual public metadata.
