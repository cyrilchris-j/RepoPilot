## How IBM Bob Was Used

IBM Bob was the primary development tool throughout this project, used for:

1. **Architecture Planning** — Working through product structure decisions before coding
2. **Component Development** — Writing React/TypeScript components with correct patterns  
3. **Design System** — Creating the Tailwind configuration and CSS utility layer
4. **AI Integration** — Structuring the IBM watsonx.ai service and API layer
5. **Debugging** — Resolving TypeScript errors and build issues
6. **Code Review** — Reviewing component interfaces and improving type safety
7. **Documentation** — Generating README and inline documentation
